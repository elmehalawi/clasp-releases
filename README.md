# Clasp

Builds of [Clasp](https://github.com/elmehalawi/clasp-site), a fast, keyboard-driven email client. Installed copies update themselves from this repository's releases.

## Download

- **Windows:** [Clasp-win-Setup.exe](https://github.com/elmehalawi/clasp-releases/releases/latest/download/Clasp-win-Setup.exe). It installs for your user only (no admin prompt) and adds Start menu and desktop shortcuts. Windows may say "Windows protected your PC" the first time: choose **More info**, then **Run anyway**.
- **macOS:** [Clasp-osx-Portable.zip](https://github.com/elmehalawi/clasp-releases/releases/latest/download/Clasp-osx-Portable.zip). Unzip it and drag Clasp to Applications.

Every version is under [Releases](https://github.com/elmehalawi/clasp-releases/releases).
